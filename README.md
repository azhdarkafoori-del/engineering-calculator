# ماشین‌حساب مهندسی

یک وب‌اپ فارسی و واکنش‌گرا برای محاسبات علمی و تبدیل واحدها؛ بدون نیاز به نصب یا کتابخانه خارجی.

## امکانات
- توابع مثلثاتی: `sin`, `cos`, `tan` و معکوس آن‌ها
- حالت درجه و رادیان
- ریشه دوم، توان، لگاریتم، لگاریتم طبیعی و فاکتوریل
- ثابت‌های `π` و `e`
- تاریخچه محاسبات در زمان استفاده
- تبدیل واحد طول، جرم، دما، فشار، انرژی و توان
- رابط کاربری فارسی و راست‌چین، سازگار با موبایل و دسکتاپ
- تجزیه‌گر عبارت ریاضی بدون استفاده از `eval`
- اجرای کامل در مرورگر و بدون ارسال داده به سرور

## اجرا
فایل `index.html` را در مرورگر باز کنید.

## انتشار با GitHub Pages
1. در مخزن به **Settings → Pages** بروید.
2. در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کنید.

همچنین workflow موجود در `.github/workflows/deploy.yml` می‌تواند سایت را با GitHub Pages منتشر کند؛ برای استفاده از آن، در **Settings → Pages → Build and deployment** منبع را روی **GitHub Actions** قرار دهید.
